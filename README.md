# CodeAlpha Cyber Security Internship

This repository contains cybersecurity projects and tasks completed during the **CodeAlpha Cyber Security Internship**.

---

## 📂 Projects & Tasks

### [Task 1: Basic Network Sniffer](./CodeAlpha_NetworkSniffer/)
A lightweight, Python-based network packet sniffer built using Scapy. Captures live network traffic, inspects packet headers (Ethernet, IPv4, IPv6, ARP, TCP, UDP, ICMP), displays TCP flags, provides payload previews, and aggregates real-time capture statistics.

- **Directory**: [`CodeAlpha_NetworkSniffer/`](./CodeAlpha_NetworkSniffer/)
- **Main Script**: [`network_sniffer.py`](./CodeAlpha_NetworkSniffer/network_sniffer.py)
- **Documentation**: [Task 1 Documentation](./CodeAlpha_NetworkSniffer/README.md)

---

### [Task 2: Phishing Awareness Training — PHISH//TRAP](./Task-2-Phishing-Awareness/)
A complete, SOC-inspired cybersecurity training application (**PHISH//TRAP**) built with React, TypeScript, Vite, and Tailwind CSS. Features interactive attack lifecycle exploration, red flags checklist with dynamic threat meter, simulated email dissection laboratory, fake website URL analyzer, social engineering vectors breakdown, real-world case studies, defensive playbook, and a 10-question evaluation quiz with instant explanations and score classification.

- **Directory**: [`Task-2-Phishing-Awareness/`](./Task-2-Phishing-Awareness/)
- **Product Name**: **PHISH//TRAP** (*Think before you click. Verify before you trust.*)
- **Tech Stack**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons
- **Documentation**: [Task 2 Documentation](./Task-2-Phishing-Awareness/README.md)
