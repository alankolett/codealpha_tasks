# CodeAlpha Cyber Security Internship

This repository contains tasks completed during the **CodeAlpha Cyber Security Internship**.

## 📂 Projects & Tasks

### [Task 1: Basic Network Sniffer](./CodeAlpha_NetworkSniffer/)
A Python network packet sniffer using Scapy that captures live packets, dissects protocol headers (IP, IPv6, ARP, TCP, UDP, ICMP), displays TCP flags and payload previews, and provides session statistics.

- **Directory**: `CodeAlpha_NetworkSniffer/`
- **Main Script**: `CodeAlpha_NetworkSniffer/network_sniffer.py`
- **Documentation**: [Task 1 Documentation](./CodeAlpha_NetworkSniffer/README.md)
